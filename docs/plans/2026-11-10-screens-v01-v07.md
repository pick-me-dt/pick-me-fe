# 1순위 화면 구현 계획 (V01~V07)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 시연 영상에 나오는 화면(V01 시작 → V02 예약 확인 → V03 매장 확인 중 → V04 제조 대기·제조 중·준비 완료 → V05 제조 전·후 지연 → V07 수령 완료)을 Figma와 같게 구현하고, 가짜 서버와 시연 컨트롤로 처음부터 끝까지 진행되게 한다.

**Architecture:** 화면은 `UiState`와 콜백만 받는 상태 없는 Compose 함수다. 주문·주행 맥락·현재 시각을 `UiState`로 바꾸는 일은 `feature/*`의 순수 함수가 하고, JVM 단위 테스트로 검증한다. 시각은 Roborazzi 스크린샷(Robolectric, 840×1184 mdpi)으로 Figma 캡처와 비교한다. 화면 전환은 `app/AppRoot`가 현재 주문 유무로 정한다.

**Tech Stack:** 기존 + Roborazzi 1.78.0, Robolectric 4.17, androidx.test.ext:junit 1.3.0, Compose ui-test

- **배치**: 세로 화면 두 칸(840 + 20 + 840)을 나란히 둡니다. 글자·버튼·여백은 세로 화면 Figma 값 그대로입니다.
- **버튼은 왼쪽 칸**: Pleos 가로 배치는 화면 맨 왼쪽에 운전자 보조 영역이 있고 그 옆에 앱이 놓여, 앱의 왼쪽 칸이 운전석에 가깝습니다.
- **오른쪽 칸**:
  - 홈(V01): 커피 그림
  - 도착 화면(V04·V05): 큰 커피 그림
  - 카드 화면(V02·V03·V06·V07 등): 주문 카드
  - 문구만 있는 화면(V00·V01 예외·V02 예외·V08): 비워 둠
- **시연 컨트롤**: 앱 영역 아래에 둡니다. 촬영 때는 `scripts/demo.sh panel off`로 숨깁니다.
